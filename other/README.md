# dotfiles

My FreeBSD+Sway profiles

## Preconditions

**The Following Softwares should be installed**

tmux
neovim
fish
exa
sway
swaybar
swaylock
alacritty
grim
slurp
rofi-wayland
wl-clipboard
yazi(file,nerd-fonts,7-zip,jq,poppler,fd,ripgrep,fzf,zoxide,resvg,ImageMagick,wl-clipboard)
bash(Used for tmux)
wf-recorder
thunderbird
zathura(pdf reader operate like vim,support mult file format)
mako(sway notify daemon),libnotify(use it's notify-send for translate-shell),gawk(use for trans),pcre2grep(used for sway_translate_clip)
gnome-dictionary(install dictd and config it in /etc/rc.conf (dict_enable="YES"))

## Install

sudo chmod +x ./install.sh

./install.sh
