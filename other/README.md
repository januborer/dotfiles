# dotfiles

My FreeBSD+Sway profiles

## Preconditions

**The Following Softwares should be installed**

tmux
neovim
fish
exa
sway
swaybar
swaylock
alacritty
grim
slurp
rofi-wayland
yazi(file,nerd-fonts,7-zip,jq,poppler,fd,ripgrep,fzf,zoxide,resvg,ImageMagick,wl-clipboard)
bash(Used for tmux)
wf-recorder
thunderbird
zathura(pdf reader operate like vim)
mako(sway notify daemon),libnotify(use it's notify-send for translate-shell)

## Install

sudo chmod +x ./install.sh

./install.sh
